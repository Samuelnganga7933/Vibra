# Design handoff

- `VIBRA_DESIGN_SPEC.md`: the spec (behaviour, states, data contracts)
- `tokens.css`: design tokens and the skeleton shimmer
- `boards/`: the 7 final screens as standalone HTML (open in a browser, or read as code)
- `screens/`: PNG renders of those boards (1440x900)

The boards use Plus Jakarta Sans (Google Fonts); the PNGs were rendered with a fallback sans, so letterforms differ slightly.
